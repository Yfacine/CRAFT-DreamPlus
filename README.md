# CRAFT-DreamPlus

![다중 플롯과 XCLIP · CRAFT-DreamPlus의 흑백 표지](https://raw.githubusercontent.com/Yfacine/Yfacine/4225c2a517e5917cab196b11c5817a3ab532f08d/assets/repositories/CRAFT-DreamPlus.webp)

AutoCAD 2024에서 다중 플롯(MPL)과 XCLIP 경계 자르기(XBT)의 재현을 준비하고 있습니다.

**현재 상태 · 개발 중 · 코어 구축 · MPL/XBT 구현 전**

## 01 / 공개 범위

AutoCAD 2024용 Windows x64 개발 프로젝트의 첫 공개 소스 스냅샷입니다. 제품 버전은 [version.json](version.json)의 0.1.0이며, 첫 사전 릴리스 태그는 v0.1.0-dev.1입니다.

AutoCAD 코어와 진단 명령 PASSAIPRO_ABOUT 및 PASSAIPRO_STATUS를 포함합니다. MPL(다중 플롯)과 XBT(XCLIP 경계 자르기)는 계획 단계입니다.

- 현재 구성은 [구조 문서](docs/ARCHITECTURE.md)에 있습니다.
- 공개 범위는 소스, 개발·검사 스크립트, 빌드 설정과 선별한 문서입니다.
- 첨부 ZIP은 소스 스냅샷입니다. 독립 빌드, 설치 및 실제 CAD 시험은 이번 공개에서 미실행입니다.

## 02 / 다음 단계

MPL·XBT의 상세 사양과 기능 검증 기준을 확정한 뒤 구현에 착수합니다.
