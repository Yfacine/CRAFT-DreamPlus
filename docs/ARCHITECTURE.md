# CRAFT-DreamPlus 구조

대상 환경은 Windows x64, AutoCAD 2024, .NET Framework 4.8입니다. 코어가 제품 정보와 구현 상태를 관리하고, AutoCAD 연결부가 진단 명령을 제공합니다. AutoCAD 코어와 진단 명령 PASSAIPRO_ABOUT 및 PASSAIPRO_STATUS를 포함합니다. MPL(다중 플롯)과 XBT(XCLIP 경계 자르기)는 계획 단계입니다.

개발 도구와 일부 검사는 기존 Windows 개발 경로 및 외부 개발 환경에 의존합니다. 이 공개 스냅샷의 독립 빌드·설치·CAD 검증은 후속 작업입니다.
